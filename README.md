# Art and Soul Dance Studio

An independently rebuilt Next.js website. Four pages: Home, Classes, About me, Contact. The former Magic Portfolio code, dependencies, content and assets are not used in this application. Its previous license still governs historical template copies, not these newly written files.

Run `npm install`, `npm run dev`, or `npm run build`.

## Draft content
Class descriptions and teacher biography are marked as placeholders. Student reviews are withheld pending verification. The Kuchipudi image is illustrative artwork, not a photograph of the teacher.
